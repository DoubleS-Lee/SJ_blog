# 애드센스 재심사 및 블로그 광고 운영

## 현재 구성

- 후기 메뉴는 관리자에게만 표시한다. `/reviews`도 서버에서 관리자 권한을 확인하며 일반 이용자는 404를 받는다. 후기는 삭제하지 않았다.
- 공개 상담 안내(`/counsel`)는 유지하고, 상담 내역과 회원 전용 결과는 사이트맵 및 검색 노출 대상에서 제외한다.
- 사이트 전체의 광고 스크립트를 제거했다. 소유 확인용 `google-adsense-account` 메타태그와 기존 `public/ads.txt`는 유지한다.
- 실제 광고는 발행된 블로그 상세 본문 아래 수동 디스플레이 광고 한 곳에만 배치한다. 홈, 소개, 문의, 후기, 상담, 로그인, 마이페이지에는 광고 컴포넌트가 없다.
- 광고 설정이 없거나 비활성화 상태면 광고 스크립트와 빈 광고 영역을 출력하지 않는다. 글의 상단·중간 로그인 유도는 본문 아래 한 번으로 정리했다.
- 소개·문의 페이지 및 푸터 링크를 추가하고, 기존 개인정보처리방침의 광고 쿠키 안내 수정사항을 보존했다.

## 재심사 전에 운영자가 확인할 내용

1. 변경사항을 배포하고 비회원 상태에서 홈, 글, 소개, 문의, 상담 안내, 개인정보처리방침을 확인한다.
2. `/reviews`는 일반 고객에게 열리지 않아야 하고, 관리자에게는 메뉴와 화면이 보여야 한다.
3. `/sitemap.xml`에 공개 글과 공개 안내만 있고 회원 전용 페이지가 없는지 확인한다.
4. 건강·투자 관련 기존 글을 직접 검토한다. 사주가 질병의 원인이나 투자 성과를 확정한다는 본문 주장은 수정이 필요하다. 공통 안내 문구만 추가했다고 해당 문제가 해결되는 것은 아니다. 이번 코드 변경은 DB의 기존 글을 수정하지 않는다.
5. 소개 페이지의 운영자 설명과 문의 경로(현재 인스타그램 @saju.roa)가 실제 운영 방식과 일치하는지 확인한다.
6. 애드센스의 사이트 확인 방식에서 기존 ads.txt 또는 메타태그를 사용한다. 그다음 사이트 상세 화면에서 재검토를 요청한다. 검토 요청·승인 여부는 별도이며 이 코드 변경으로 승인이 보장되지는 않는다.

## 승인 후 수동 광고 활성화

애드센스 대시보드의 `광고 → 사이트 기준 → sajuroa.com`에서 **자동 광고를 끄고**, 기존 광고 최적화 옵션도 확인한다. 자동 광고는 수동 광고와 같은 스크립트를 사용하므로 사이트 코드만으로 대시보드의 자동 광고 설정을 끌 수 없다.

`광고 → 광고 단위 기준 → 디스플레이 광고`에서 반응형 광고 단위를 생성하고 코드의 `data-ad-slot` 숫자를 확인한다. 게시자 ID는 현재 `ca-pub-5713452367621432`이다. 광고 단위 ID를 게시자 ID로 대체하거나 임의로 만들면 안 된다.

배포 환경 변수:

```dotenv
ADSENSE_ENABLED=true
ADSENSE_BLOG_SLOT=실제_data-ad-slot_숫자
```

심사 대기 중이거나 광고 단위를 아직 만들지 않았다면 `ADSENSE_ENABLED=false`로 두고 슬롯은 비워 둔다. 값 설정 후 재배포하고 실제 글에서 확인한다. 개발 모드에서는 `data-adtest="on"`을 사용한다. 테스트에서 광고를 클릭하지 않는다.

광고 차단기, 미승인, 광고 미충원으로 광고가 표시되지 않을 수 있다. 스크립트 로드 오류와 미충원 상태에서는 광고 영역을 숨긴다.

## 보안 및 렌더링 변경

Google은 광고 리소스 도메인이 바뀔 수 있어 nonce 기반 strict CSP를 안내한다. `src/proxy.ts`가 매 응답에 새 nonce를 만들고, Next.js 런타임·구조화 데이터·광고 스크립트에 적용한다. 루트 Provider는 클라이언트 이동 중에도 현재 문서의 nonce를 유지한다.

정적 HTML 셸과 요청별 nonce는 호환되지 않아 `cacheComponents`를 끄고 요청별 HTML 렌더링을 사용한다. 글 상세 조회는 `unstable_cache`로 옮겨 `posts` 태그 무효화와 60초 재검증을 유지하며 목록 조회 캐시도 유지한다. 변경 전보다 HTML 서버 렌더링 비용이 늘 수 있으므로 배포 후 응답 시간과 서버 사용량을 확인한다.

스크립트는 nonce와 `strict-dynamic`으로 제한한다. Google 가이드 호환성을 위해 `unsafe-eval`과 HTTPS 광고 리소스(연결·이미지·프레임 등)는 허용하며 `object-src 'none'`, `base-uri 'none'`, 프레임 임베딩 금지는 유지한다. 광고 도메인을 임의로 고정한 기존 정책과의 차이다.
